# 跨境电商库存管理系统需求文档

## 1. 产品定位
面向小型外贸公司的一体化 SaaS 库存与上架工作台，统一管理多仓、多渠道库存、SKU、产品图片、数据看板和 AI 产品 Listing 生成。

## 2. 用户与场景
- 老板/运营负责人：查看库存健康度、销售趋势、补货风险和经营指标。
- 商品运营：创建新品、维护 SKU/SPU、管理 Listing 文案与平台发布状态。
- 仓库/采购：处理入库、出库、调拨、盘点、低库存补货提醒。
- 设计/内容运营：管理主图、场景图、尺寸图、视频和平台图片规范。

## 3. 核心需求
### 3.1 实时库存管理
- 支持本地仓、海外仓、FBA、第三方仓库存汇总。
- 支持入库、出库、调拨、锁定、盘点、退货库存流水。
- 支持低库存、安全库存、缺货、滞销、周转天数预警。
- 支持平台订单或 ERP API 同步后自动扣减库存。

### 3.2 新品上架
- 新品创建向导：基础资料、规格属性、价格、物流、合规、图片、Listing。
- 支持草稿、待补图、待审核、待发布、已发布状态流转。
- 支持按 Amazon、eBay、Shopify、独立站等渠道配置字段模板。

### 3.3 产品图片管理
- 支持图片上传、标签、版本、用途、渠道尺寸规范校验。
- 支持主图、细节图、场景图、尺寸图、包装图、证书图分类。
- 支持图片与 SPU/SKU/Listing 绑定，保留历史版本。

### 3.4 SKU 管理
- SPU-SKU 多规格模型，支持颜色、尺寸、插头、语言、套装等变体。
- 支持条码、供应商货号、平台 SKU、仓库 SKU 映射。
- 支持批量导入、批量编辑、属性模板与唯一性校验。

### 3.5 数据可视化
- 库存总览、渠道库存、库存健康度、动销/滞销、缺货风险、销售贡献。
- 支持按市场、渠道、仓库、品类、时间维度筛选。
- 支持导出 Excel/CSV 与订阅日报。

### 3.6 AI 生成产品 Listing
- 输入：产品标题草稿、卖点、规格、目标国家、渠道、图片、竞品关键词。
- 输出：多语言标题、五点描述、长描述、搜索关键词、合规风险提示。
- 支持品牌语气、禁用词检查、人工编辑和版本对比。

## 5. 技术方案
### 5.1 前端
- MVP 阶段采用原生 HTML/CSS/JavaScript 静态单页应用，便于快速交付可视化原型。
- 现代 SaaS 风格：侧边栏导航、卡片、渐变、数据图表、响应式布局。
- 工程化阶段建议升级为 React + Vite + TypeScript，并引入 React Router、TanStack Query、Zustand、ECharts。

### 5.2 后端
- API：Node.js/NestJS 或 FastAPI。
- 数据库：PostgreSQL 存储商品、SKU、库存、图片元数据、Listing 版本。
- 缓存与实时：Redis + WebSocket/SSE 推送库存变更。
- 文件：S3 兼容对象存储保存图片，CDN 分发。
- AI：通过模型 API 生成 Listing，保存 Prompt 模板、生成记录和人工审核结果。

### 5.3 数据模型摘要
- ProductSPU：产品主档、品牌、类目、生命周期状态。
- ProductSKU：规格组合、条码、供应商编码、平台映射。
- InventoryBalance：仓库、SKU、可售、锁定、在途、残次库存。
- InventoryTransaction：库存流水类型、数量、来源单据、操作人。
- MediaAsset：图片地址、标签、尺寸、用途、绑定关系。
- ListingDraft：渠道、语言、标题、卖点、描述、关键词、AI 版本。

## 6. MVP 优先级
- P0：总览仪表盘、库存列表、SKU 管理、新品上架基础流程。
- P1：图片资产库、AI Listing 生成、库存预警与补货建议。
- P2：渠道 API 集成、实时推送、高级报表、权限审批流。
